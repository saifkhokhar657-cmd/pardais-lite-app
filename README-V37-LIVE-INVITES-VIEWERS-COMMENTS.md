# V37 — Live invites, entries, viewers and comments

- Real host-to-host co-host invites now create pending invites and poll on the recipient host screen.
- Recipient gets Accept / Reject controls. Accept switches into the inviter's live room as a co-host and changes the live mode to ONE VS ONE. Reject leaves the host in Solo Live and the sender receives a rejection notice.
- Live entries are persisted per room and broadcast to all connected participants, not only the entering viewer.
- Viewer count is based on live-room members, so the host counts as one and a second participant makes the count two.
- Viewer count can be tapped to open a realtime viewer list with profile/level data.
- New comments are always anchored to the bottom; older comments remain above and can be scrolled upward.
- Existing live UI, gifts, moderation and profile actions are preserved.
