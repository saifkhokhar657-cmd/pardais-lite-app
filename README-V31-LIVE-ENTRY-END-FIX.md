# Pardais Lite V31 — Live End + Entry Animation

- Live Discover cards are refreshed every 1.5 seconds and only active `status=live` rooms are shown.
- When a host ends a broadcast, the room disappears from the live card list on the next refresh.
- Viewers polling the active room detect the ended room and see an overlay: `This broadcast has ended`, followed by a 5-second automatic return to the Live page. A `Go to Live Now` button is also available.
- Entry animation is driven by the logged-in viewer's real profile level, capped at the app's Level 50 maximum.
- Entry tiers: Level 10 Silver, 20 Gold, 30 Diamond, 40 Royal, 50 Ultimate.
- Levels below 10 have no special milestone entry.
- Existing Live UI, comments, gift drawer, host controls, camera/mic behavior, and double-tap hearts are preserved.
