# V50 — Guest/Co-host bottom controls

When the authenticated user is an active guest/co-host stage participant, the live UI now exposes:
- Comment
- Gift
- Share
- Microphone toggle
- Camera toggle
- Double-tap hearts remain enabled

The normal audience viewer remains restricted to viewer actions. Solo host UI is preserved. Stage participants receive a dedicated CSS class so viewer-only mobile layout rules cannot collapse their controls into a single gift button.
