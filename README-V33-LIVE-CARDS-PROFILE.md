# V33 — Live Cards + Profile Production Refinements

- Empty Live/Discover state keeps the blue/purple app background instead of a black half-screen.
- Live cards no longer render a video; the host profile picture fills the card background.
- Card mode labels are derived from live state: SOLO, ONE VS ONE, PK, GUEST.
- Live cards show the host level badge and remain filtered to fresh heartbeats.
- Profile avatars are clipped inside their circular frame.
- Profile picture can be opened full-screen and saved.
- Edit Profile supports profile picture upload, bio, phone, age derived from date of birth, email display, social fields and a 7-day display-name change lock.
- Existing username remains locked after registration.
